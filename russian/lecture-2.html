ОСНОВНОЕ ОПРЕДЕЛЕНИЕ08 / 57

Что такое эконометрическая модель?

Эконометрическая модель математически выражает теоретические связи между экономическими явлениями на основе статистических данных и позволяет оценивать их количественную зависимость.
Экономическая теория + математическое выражение + данные + статистический метод = эконометрическая модель.
ОСНОВНАЯ ФОРМУЛА09 / 57

Анатомия модели

Yᵢ = β₀ + β₁Xᵢ + uᵢ
Yᵢ — зависимая переменная, результат, который хотим объяснить.
Xᵢ — объясняющая переменная, фактор, связанный с результатом.
β₀ — свободный член, исходный уровень модели.
β₁ — параметр, количественная связь X и Y.
uᵢ — случайная ошибка, не включённые в модель факторы.
ЭКОНОМИЧЕСКАЯ ИНТЕРПРЕТАЦИЯ10 / 57

Формула — не просто набор символов

Продажиᵢ = β₀ + β₁Рекламаᵢ + uᵢ
Продажи — зависимая переменная; реклама — объясняющий фактор.
Ŷ = 50 + 3X
Если X выше на 1 единицу, модель связывает это в среднем с Y выше на 3 единицы.
Это само по себе не означает «X вызвал Y».
ОШИБКА u11 / 57

Зачем в модели случайная ошибка?

Продажиᵢ = β₀ + β₁Рекламаᵢ + uᵢ
В u могут попадать качество продукта, сезон, действия конкурентов, вкусы потребителей, экономическая ситуация, погода, ошибки измерения и другие факторы.
В реальной экономике Y редко полностью объясняется одним X.
НЕОПРЕДЕЛЁННОСТЬ12 / 57

Экономические связи — не механические тождества

Детерминированно: Y = 2X — при известном X значение Y полностью определено.
Стохастически: Y = β₀ + β₁X + u — даже при известном X Y может различаться из-за других факторов.
Эконометрические модели учитывают неопределённость через случайную компоненту.
СРАВНЕНИЕ13 / 57

Математическая и эконометрическая модель

Математическая: C = a + bY; теоретическая связь; параметры могут быть символическими; случайная компонента не обязательна.
Эконометрическая: Cᵢ = β₀ + β₁Yᵢ + uᵢ; работает с данными; параметры оцениваются; присутствует случайная компонента; гипотезы проверяются эмпирически.
Эконометрическая модель связывает теорию с данными.
ЦЕЛИ14 / 57

Три основные задачи эконометрической модели

1) Объяснение: почему одни дома дороже других?
2) Прогноз: сколько могут составить продажи в следующем квартале?

ПРОГНОЗ И ОБЪЯСНЕНИЕ15 / 57

Prediction и explanation — одно и то же?

Прогноз: «Какой клиент может отменить подписку?» Цель — максимально точное предсказание.
Экономическое объяснение: «Какие факторы связаны с вероятностью отмены?» Цель — понять экономический смысл связи.
Высокая точность прогноза не всегда означает сильное экономическое объяснение.

«Больше рекламы — выше продажи»: достаточно ли этого?

Компания может увеличивать рекламу перед праздниками, когда ожидается высокий спрос, при запуске продукта или во время крупных акций.

Может ли сегодняшний результат зависеть от вчерашнего?

ПАРАМЕТРЫ23 / 57

Что экономически означают β₀ и β₁?

Yᵢ = β₀ + β₁Xᵢ + uᵢ
β₀ — исходный уровень модели при X = 0.
β₁ — как в среднем различается Y при изменении X на одну единицу, в рамках условий модели.
Точная интерпретация β₁ зависит от функциональной формы и единиц измерения.

ТИП ДАННЫХ27 / 57

Time series: один процесс во времени

Инфляцияₜ = f(ВалютныйКурсₜ, ПроцентнаяСтавкаₜ, …)
2017 → 2018 → 2019 → … → 2026.
Временной ряд — последовательные значения экономического показателя во времени.
Примеры: инфляция, валютный курс, ВВП, процентная ставка, цены акций.

Панель позволяет одновременно изучать различия между объектами и изменения во времени.
ФУНКЦИОНАЛЬНАЯ ФОРМА29 / 57

Основная идея линейной модели

Y = β₀ + β₁X + u
В линейной модели связь X и Y линейна по параметрам.
Изменение X на одну единицу связано с ожидаемым изменением Y, которое выражает β₁.
Линейная модель — важная отправная точка эконометрического анализа.

Логарифмы для процентных изменений

ln(Yᵢ) = β₀ + β₁ln(Xᵢ) + uᵢ

REAL ECONOMETRIC RESEARCH33 / 57

Как Uber изучал реакцию спроса на изменение цены?

Около 50 млн индивидуальных наблюдений.
Метод: regression discontinuity design.
Cohen, Hahn, Hall, Levitt и Metcalfe использовали скачки в алгоритме surge pricing для оценки эластичности спроса.
Цена → запросы поездок → эластичность спроса → бизнес-решение.
Больших данных недостаточно: нужен правильный дизайн исследования.
Источник: NBER Working Paper No. 22627, 2016.
ИНТЕРПРЕТАЦИЯ КЕЙСА34 / 57

50 млн наблюдений не решают проблему автоматически

DATA: много наблюдений ≠ автоматическое causal evidence.

DECISION: эластичность спроса, pricing и consumer surplus.
Эконометрика = вопрос + экономическая логика + данные + подходящий метод.

2. Теория направляет построение модели

Qᵈ = f(P, Y, Pₛ, P꜀, T, …)
P — цена товара; Y — доход; Pₛ — цена заменителя; P꜀ — цена дополняющего товара; T — вкусы и предпочтения.
Теория помогает определить важные переменные, ожидаемое направление связи и экономическую логику модели.
ОПЕРАЦИОНАЛИЗАЦИЯ42 / 57

3. Превратить теоретическое понятие в измеряемую переменную

«Качество жилья»: площадь м², число комнат, возраст здания, ремонт 1/0, расстояние до центра км.
«Образование»: годы обучения, уровень диплома, результат теста.
Теоретическое понятие должно быть переведено в измеряемые данные.

Population model: Yᵢ = β₀ + β₁Xᵢ + uᵢ

7. Результат регрессии — не конец исследования

ИНТЕРПРЕТАЦИЯ КЕЙСА56 / 57

Как правильно сформулировать результат?

Условный пример: β̂₁ = 350.
Неправильно: «Delivery увеличивает продажи на 350 единиц».
Правильно: «При контроле других включённых факторов в дни с delivery продажи были в среднем на 350 единиц выше».
Почему осторожно: delivery мог включаться в дни высокого спроса, вместе с акциями или при сезонных факторах.
Эконометрическая интерпретация начинается с коэффициента, но не заканчивается им.
ИТОГОВАЯ ЛОГИКА57 / 57

Главная схема эконометрического мышления

Вопрос → теория → переменные → данные → модель → оценивание → проверка → экономическая интерпретация → прогноз / решение.
Цель эконометрики — не просто найти уравнение, а получить надёжный, основанный на данных ответ на экономический вопрос.
Модель — упрощение реальности; в ней есть случайность; Y и X надо определять правильно; корреляция не равна причинности; результат без экономической интерпретации недостаточен.
Следующий этап: оценивание регрессионной модели и интерпретация коэффициентов.
